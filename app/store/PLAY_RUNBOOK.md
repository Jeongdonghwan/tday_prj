# 구글 플레이 출시 런북 (콘솔 페이지별)

준비물(이 폴더): icon-512.png · feature-graphic-1024x500.png · listing.md(문구) ·
data-safety.md(설문 답) · review-account.md(심사 계정, 로컬 보관) · 프로덕션 AAB(EAS에서 다운로드)

> ⚠️ 신규 **개인** 개발자 계정은 프로덕션 출시 전 **비공개 테스트**(테스터 모집, 약 14일)를
> 거쳐야 합니다. 콘솔 대시보드에 정확한 요건이 표시되니 그 안내를 기준으로 진행.

## 1. 개발자 계정 가입 (1~3일)
1. https://play.google.com/console → 구글 계정 로그인 → 계정 만들기 → **개인**
2. 개발자 이름·연락처 → **$25 결제**
3. 신원확인(신분증) 요청 시 제출 → 승인 대기

## 2. 앱 만들기
콘솔 → 모든 앱 → **앱 만들기**: 이름 `오늘연애`, 기본 언어 한국어, **앱**, **무료** → 만들기

## 3. 대시보드 "앱 설정" 작업 채우기 (위에서부터)
| 항목 | 입력값 |
|---|---|
| 개인정보처리방침 | `https://todayloves.com/privacy` |
| 앱 액세스 권한 | 제한됨 → review-account.md 내용 입력 |
| 광고 | **예, 광고 포함** |
| 콘텐츠 등급 | 설문: 소셜/커뮤니케이션, 사용자 생성 콘텐츠 예, 상호작용 예 |
| 타겟층 | **18세 이상** |
| 뉴스 앱 / 코로나 / 정부 앱 / 금융 | 모두 아니오/없음 |
| 데이터 보안 | data-safety.md 표 그대로 |
| 앱 카테고리 | 앱 → **소셜**, 태그: 연애·커뮤니티 |
| 스토어 등록정보 | listing.md 문구 + icon-512 + feature-graphic + 폰 스크린샷 2장+ |

## 4. 비공개 테스트 (개인 계정 필수 관문)
1. 테스트 및 출시 → **비공개 테스트** → 새 버전 만들기
2. 앱 서명: **Google 생성 키 사용**(기본) → 계속
3. **AAB 업로드**(EAS 빌드 다운로드 파일) → 저장 → 검토 → 출시
4. 테스터 탭 → 이메일 목록(지인 구글계정 12~20개) → 저장 → 모집 링크 공유
5. 요건 기간 유지하며 테스트. 이 기간에 아래 5번(키 해시) 처리

## 5. ⚠️ 카카오 키 해시 추가 (스토어 설치본 카카오 로그인 필수)
Play는 앱을 **자체 키로 재서명**하므로 그 키 해시도 카카오에 등록해야 함:
1. Play Console → 테스트 및 출시 → 설정 → **앱 서명** → "앱 서명 키 인증서" **SHA-1** 복사
2. SHA-1 → base64 키해시 변환(Claude에게 SHA-1 주면 변환) 
3. 카카오 콘솔(본앱) → 플랫폼 → Android → 키 해시에 **추가** (기존 해시 유지)

## 6. 프로덕션 출시
1. 테스트 요건 충족 → 대시보드 "프로덕션 액세스 신청" → 설문 제출
2. 승인 후: 프로덕션 → 새 버전 만들기 → AAB 업로드 → 출시 (심사 수시간~7일)
3. 게시되면: 서버 `.env` `APP_INSTALL_URL=<플레이스토어 URL>` + `systemctl restart todaylove`

## 업데이트 배포 (이후 반복)
```bash
cd app && npx eas-cli build --profile production --platform android
# 완료 후 AAB 다운로드 → 콘솔 프로덕션 새 버전으로 업로드 (versionCode 자동 증가)
```
