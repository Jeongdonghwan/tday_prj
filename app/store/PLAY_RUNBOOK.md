## 4. 비공개 테스트 (필수 관문)
1. 테스트 및 출시 → **테스트 → 비공개 테스트** → 새 버전 만들기
2. 앱 서명: **Google 생성 키 사용**(기본) → 계속
3. **AAB 업로드**(EAS production 빌드) → 저장 → 검토 → 출시
4. 테스터: 대행 업체 방식대로 —
   (a) "이메일 목록"에 업체가 준 지메일 추가, 또는
   (b) **비공개 테스트 옵트인 링크**를 업체에 전달 → 업체가 12~20명 참여
   - 참여자는 링크 열고 "테스터 되기" 수락 → 플레이스토어에서 설치
5. **14일 연속 · 최소 12명 옵트인 유지**. 이 기간에 아래 7(키해시) 처리

## 6. 프로덕션 출시 (14일 요건 충족 후)
1. 대시보드 **"프로덕션 액세스 신청"** → 설문(앱 소개·테스트 방식) 제출
2. 승인 후: 프로덕션 → 새 버전 → 같은 AAB → 국가 대한민국(또는 전체) → 출시
3. 심사 수시간~7일 → 게시 = 플레이스토어 공개
4. 게시 직후: 서버 `.env` `APP_INSTALL_URL=<플레이 URL>` + `systemctl restart todaylove`

## 7. ⚠️ 스토어 설치본 카카오 로그인 — 앱 서명 키 해시 추가
Play가 AAB를 **자체 키로 재서명**하므로 그 키 해시도 카카오에 등록해야 스토어 앱에서 카카오 로그인됨.
1. Play Console → 테스트 및 출시 → 설정 → **앱 서명** → "앱 서명 키 인증서" **SHA-1** 복사
2. SHA-1 → base64 키해시 변환 (Claude 에게 SHA-1 전달)
3. 카카오 콘솔(본앱) → 플랫폼 → Android → 키 해시에 **추가**(기존 EAS 해시 유지)

## 업데이트 배포 (이후 반복)
```bash
cd app && npx eas-cli build --profile production --platform android
# 완료 후 AAB 다운로드 → 콘솔 프로덕션 새 버전으로 업로드 (versionCode 자동 증가)
```
