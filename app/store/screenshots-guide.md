# 스크린샷 촬영 가이드 (전화 스크린샷 2~8장, 세로)

폰에 설치된 앱(개발빌드 또는 비공개테스트 설치본)에서 **세로 화면 캡처**하면 됩니다.
규격: 세로 스크린샷 그대로 OK (비율 9:16 근처, 320~3840px). 편집 불필요.

## 추천 6장 (순서 = 스토어 노출 순서)
1. **홈** — 실시간 인기 + 오늘의 투표가 보이는 첫 화면
2. **커뮤니티 피드** — 글 몇 개 + 투표 카드가 같이 보이게
3. **투표 결과** — 글 상세에서 투표 후 결과바(우세 로즈)가 보이는 장면
4. **연애 심리테스트 결과** — 아바타 + 궁합(잘 맞는/부딪히는 유형) 화면
5. **오늘의 연애 이슈** — 이슈 상세 + 투표
6. **커플 공간** — 마이 탭 D-day 카드 (또는 캘린더)

## 팁
- 상태바의 개인정보(시간·배터리는 OK, 알림 아이콘 정리) 확인
- 콘텐츠가 비어 보이면 시드 데이터 있는 운영 서버 연결 빌드로 캡처
- 캡처 후 그대로 Play Console → 스토어 등록정보 → "휴대전화 스크린샷"에 업로드
