# 데이터 보안 양식 답변 시트 (Play Console → 앱 콘텐츠 → 데이터 보안)

콘솔 설문 순서대로 그대로 선택하면 됩니다.

## 1. 데이터 수집/공유 여부
- 앱이 사용자 데이터를 수집하거나 공유하나요? → **예(수집함)**
- 수집한 데이터를 제3자와 공유하나요? → **아니요**
- 전송 중 데이터가 암호화되나요? → **예** (전 구간 https)
- 사용자가 데이터 삭제를 요청할 수 있나요? → **예** (앱 내 [마이 → 회원 탈퇴] 즉시 삭제)

## 2. 수집하는 데이터 유형 (체크할 항목)

| 카테고리 | 항목 | 수집 | 목적 | 필수/선택 |
|---|---|---|---|---|
| 개인 정보 | 이메일 주소 | ✔ | 계정 관리 | 선택(카카오 동의 시)/이메일가입 시 필수 |
| 개인 정보 | 사용자 ID (소셜 식별자·닉네임) | ✔ | 계정 관리, 앱 기능 | 필수 |
| 메시지 | 기타 인앱 메시지(게시글·댓글) | ✔ | 앱 기능 | 선택 |
| 사진 및 동영상 | 사진 (게시글 첨부 이미지) | ✔ | 앱 기능 | 선택 |
| 앱 활동 | 앱 상호작용 (투표·테스트 응답) | ✔ | 앱 기능 | 선택 |
| 기기 또는 기타 ID | 기기 ID (푸시 토큰) | ✔ | 앱 기능(알림) | 선택 |

- 각 항목의 "데이터 처리 방식": **수집됨** (공유 아님) / **임시 처리 아님**
- 각 항목 목적: 위 표의 목적만 체크 (광고/마케팅 목적 수집 = 없음)

## 3. 수집하지 않는 것 (체크하면 안 되는 항목)
위치, 이름(실명), 전화번호, 금융 정보, 건강 정보, 연락처, 검색 기록, 설치된 앱 정보
